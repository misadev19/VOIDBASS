# VOIDBASS

A fictional audio brand website created as a portfolio project.

Designed with a dark and immersive visual style, the website combines bold typography, smooth animations, and a modern e-commerce experience to create a distinctive brand identity.

## Live Demo

[View Live Demo](https://voidbass.vercel.app/)

## Features

- Responsive design
- Product listing and product detail pages
- Shopping cart functionality
- Quantity adjustment and item removal
- Dynamic cart item count
- Smooth scroll animations
- Scroll-triggered animations with GSAP
- Interactive hover effects
- Responsive layouts for desktop and mobile devices

## Tech Stack

- React
- JavaScript
- HTML
- CSS
- Vite
- React Router
- GSAP
- React Icons
- Git
- GitHub
